# Betti 🐝

Egy játékos randi-időpont app: Betti kiválasztja az időpontot (a naptárával ütközésmentesen), a helyszínt te intézed.
Magyarul, vicces angol és kínai fordítással. Statikus oldal, nincs szerver, nincs követés, minden a böngészőben marad.

## Helyszín megadása

A linkhez fűzd hozzá: `?helyszin=Borbíróság` – és a boríték meg a jegy már ezt mutatja (alapból "Meglepetés").

## Deploy

Push a `main` ágra → GitHub Actions (`.github/workflows/pages.yml`) kirakja GitHub Pages-re.
